# 支持范围与验收状态

当前为 1.1.0a1 预览版。目标平台是 Windows 10/11 x64、64 位 Python 3.10+ 或便携版。
尚未验证 Windows ARM64、32 位解释器、Windows Server、多用户提权后的原用户 HKCU 映射。

已验证：规则构建、沙箱扫描/修复/复检、PE 普通导入静态分析、应用私有 Qt 依赖识别、
运行时配置家族读取、文件与临时 HKCU 键撤销、用户后续修改冲突保护。
签名验证失败会阻止安装器执行；下载仅允许列出的官方 HTTPS 主机并限制重定向。

尚需在可回滚虚拟机及真实设备上验收：各代运行库安装成功/失败/重启，音频恢复测试音，
打印队列和测试页，多种 Windows 版本/语言、企业策略、离线或代理网络。
这些操作未作为本机自动测试执行。源代码测试通过不等于修复成功率已得到统计验证。

撤销只覆盖通过本程序记录的注册表值、服务状态/启动类型及受支持的文件替换。
不能整体卸载运行库、撤销 regsvr32、恢复已删除的临时文件或打印任务、恢复被结束的进程。
新建注册表值撤销后可能保留空父键。中断、备份损坏或与当前状态冲突时会停止自动恢复。
服务触发器和系统策略可能再次改变状态。部分失败的撤销记录需人工检查。

诊断应用不会启动或加载目标文件。它检查普通直接导入和 .runtimeconfig.json，
未完整模拟延迟导入、递归依赖、SxS、PATH、插件、KnownDLL 优先级、.NET rollForward 或自包含宿主。
“尚未定位”表示需要进一步诊断，不是确认丢失。API Set 不按同名实体文件计为缺失。
默认全机 DLL 清单仅检查当前解释器架构，x86 应用请通过“诊断应用”单独检查。

修复状态：verified=复检通过，failed=执行/复检失败，unverified=验证未完成，
pending_reboot=需要重启后重新检测，planned=仅预览。重启后的验证需用户重新扫描。
退出码：0=命令完成，2=修复失败，3=尚待验证。CLI 的 --json 输出尚非统一机器协议。

便携版尚无本项目发布者的代码签名。可通过公开源代码自行构建；下载后核对 SHA-256。
修复工具不能处理所有驱动、硬件损坏或系统无法启动的问题，也不承诺完整替代商业产品。
