# 产品与研究材料

KSR 以 Python 标准库、Windows 系统接口和独立可读 JSON 规则实现功能。
项目曾参考商业工具的功能划分及本地逆向研究，已有部分优化规则按研究结果重新编写；
不将其宣传为未接触原件的净室实现。

公开发行只包含产品源码、测试、原创图形元素和构建文档。
原商业软件安装包、提取的 Lua 脚本、解码配置原文、内存转储、反编译 C、
原厂图片和商标、本机运行日志、注册表备份与个人数据不属于发行内容。
研究材料中的“存在规则”与“当前启用”曾有差异，产品不自动导入这些研究索引。

运行库按用户选择从微软官方 HTTPS 地址下载，执行前通过 Windows 验证签名状态及发布者。
微软安装包适用其自身许可，不随本仓库分发。发行版中 Python、PyInstaller 等构建组件
适用各自许可；发布时附带相关许可文件。

本项目不使用商业软件会员校验或付费接口。官方版本全部功能免费，无广告、无账户系统，
不向服务器上传扫描或修复记录。GitHub 发布服务与用户主动下载的微软组件会产生网络请求。
