# 对标功能与替代验收矩阵

目标是覆盖商业工具的检测、修复、复检、异常处理与受支持的撤销能力。当前为 1.1.0a7 预览版，不能声明 100% 替代。
组件存在、规则数量、单元测试通过和健康设备功能正常，均不能折算为商业工具故障修复覆盖率。

## 本次截图中的六类项目

| 原项目 | 当前处理 | 验收边界 |
|---|---|---|
| MFC / ATL 框架库 | 2005/2008/2010/2012/2013 与 CRT 一起按 x86/x64 提供官方安装和复检；MFC v14 单列 | 旧 SxS 组件检查清单及文件架构；现代组件检查正确的系统目录。MFC/ATL 7.1 需要原应用安装包 |
| VC++ 2008 | 两种架构独立安装，校验 SHA-256 与微软签名 | 下载及签名已验证，真实缺失故障下的完整安装和重启矩阵未完成 |
| VC++ 2002–2013 其余运行库 | 2010/2012/2013 转入可安装项；2002/2003 单列说明 | 新版不能替代 msvcr70/71；不能将全局缺失视作应用目录缺失 |
| 开机启动项过多 | 管理面板，用户明确选择后批量停用 Run 值，保存可撤销快照并复检 | 默认不选；不处理服务、驱动、计划任务或启动文件夹；不承诺性能提升 |
| 游戏专用运行库 | OpenAL 与 NVIDIA PhysX 分开检测和官方安装 | 不要求 PhysXCore/Device 位于 System32；不代替游戏版本、SDK 和 GPU 功能验证 |
| MSXML 4.0 | 官方 KB2758694 安全更新包安装，按 x86 检测文件 | 已核对内含解析器 MSI、哈希与签名；尚无干净机器安装/COM 功能验收，仍为过时兼容组件 |

固定的 13 个组件包均来自官方 HTTPS，无需镜像；包版本、来源、哈希、发布者、安装参数随源码公开。
执行前再次校验，失败停止；不下载散装 DLL 写入系统目录，不绕过签名或许可流程。

## 完整替代所缺的验证

| 功能面 | 已有能力或证据 | 尚缺的替代证据 |
|---|---|---|
| 综合检测、DLL、运行库 | 可读规则、PE 架构分析、组件清单与安装后复检 | 原工具完整功能清单；同一缺失/损坏/版本冲突样本在两工具的对照结果 |
| 常见启动错误码、软件崩溃 | 应用静态依赖诊断、.NET 运行时匹配 | 具体应用动态加载、错误码原因分类与同故障恢复样本 |
| 系统设置与优化 | 部分注册表/服务检测、操作记录与冲突保护撤销 | 不同 Windows 构建/语言/企业策略下的效果与副作用测试 |
| 声音 | 服务/端点检查；用户已确认实际播放正常 | 在独立设备上注入驱动/端点/服务故障后的恢复，与原工具对照 |
| 游戏 | 图形/音频/手柄依赖与部分组件安装 | 游戏版本、反作弊、GPU 驱动、掉帧/黑屏及私有 SDK 故障对照 |
| 电脑卡慢、启动 | 部分进程/设置诊断；显式 Run 启动项管理 | 可重复开机、CPU/IO/内存性能基准和回归收益证据 |
| 打印机 | 队列/服务检测；用户已确认网络打印出纸正常 | 真实驱动/权限/脱机/共享/卡队列故障修复矩阵 |
| 安装器与重启 | 保留返回码、3010 待重启、复检未完成独立状态 | 各安装包首次安装/修复/较新版本/取消/重启/离线/代理策略全矩阵 |
| 撤销 | 受支持的注册表、服务及文件变更快照和冲突检查 | 安装器整体卸载、硬件/驱动变更及所有系统修改的等价恢复 |

要声明完全替代，需要可重复的双机或虚拟机快照测试：记录原始故障、两工具版本、各自检测与修复结果、重启后状态及副作用。
未知或未实测项始终保留为未验证，不通过隐藏提示或直接标绿来完成目标。
